# Smart Mail AI

### AI-Powered Email Classification System

Smart Mail AI is a machine learning-based email classification system that automatically analyzes incoming emails and categorizes them based on their importance.

## What It Does

* Analyzes email content
* Classifies emails automatically
* Categorizes emails into:

  * **Important**
  * **Average**
  * **Unimportant**
* Helps users quickly identify emails that need attention
* Reduces the time spent manually checking emails

## How It Works

```text
Email Input
     ↓
Text Processing
     ↓
Feature Extraction
     ↓
ML Classification
     ↓
Importance Category
```

## Categories

| Category    | Meaning                                |
| ----------- | -------------------------------------- |
| Important   | Requires immediate or timely attention |
| Average     | Useful but not urgent                  |
| Unimportant | Low-priority email                     |
